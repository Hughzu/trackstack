# Challenge 12 - Month Snapshot

Objectif:
- calculer le total du mois courant de `now`
- calculer le total du mois precedent
- calculer `delta = current - previous`
- calculer `deltaPct` si `previous > 0`, sinon `nil`

Tu modifies seulement `challenge.go`.

Commande:

```bash
go test ./challenges/go/12_month_snapshot
```
