# Challenge 07 - JSON Handler

Objectif:
- creer un handler HTTP `POST`
- refuser les methodes non `POST`
- decoder du JSON en refusant les champs inconnus
- valider `name` non vide et `count` > 0
- appeler le store et repondre en JSON

Tu modifies seulement `challenge.go`.

Commande:

```bash
go test ./challenges/go/07_json_handler
```
